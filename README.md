A program that writes a single one-line, one-star review from a houseplant
about its human owner — under 280 characters — to `/output/entry.txt`.

The plant's grievance: watered like a rumour, called "low maintenance" in
front of guests, and left sitting in a pot with no drainage. One star,
earned the hard way — through spite-powered photosynthesis.

## Run

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
